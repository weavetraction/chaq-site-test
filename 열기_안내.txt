차큐(chaq.kr) 프론트엔드 실데이터 시안

[실행 방법]
1. 이 ZIP을 전부 압축 해제합니다.
2. index.html 을 더블클릭합니다. (Chrome / Edge 권장)

[구성]
- index.html           : 메인 화면
- pages/               : 재고특가·빠른인도·견적조회·상세·이벤트·아티클·마이페이지
- pages/data/quotes.js : 실제 차량/비용 데이터 (재고특가 187·빠른인도 187·견적조회 703)
- stylesheets/         : redesign.css(메인), detail-overrides.css(하위 페이지)
- scripts/             : redesign.js(메인), detail-overrides.js(원본 차량선택 페이지용)
- assets/, font/       : 아이콘·Pretendard 폰트

[실데이터 테스트]
- 재고특가/빠른인도 : 상단 조건칩(계약기간·초기비용·주행거리)·필터·정렬 → 카드 월납입금 실시간 반영
- 견적조회         : 브랜드→모델→트림 단계 선택 후 조건에 맞는 최저가 1대 표시
- 상세페이지       : 조건 변경 시 월납입금·확정금액·인수 시 총 비용(월납×개월+잔가) 실시간 계산

[참고]
- 차량 이미지는 데이터에 URL이 없어 임시 플레이스홀더로 표시됩니다.
- 카카오 로그인·상담 접수·운용리스 비용 등 서버 기능은 백엔드 연동 시 붙습니다.
- 브랜드/모델/트림 선택, 금리계산기, 즉시출고, 신차할인 화면은 원본 chaq.kr 그대로이며 인터넷 연결 시 정상 표시됩니다.
