| **표시명 정리** | 벤츠 보도자료 표기 "더 뉴 메르세데스-벤츠 GLE 450 d 4MATIC 쿠페" → "GLE 450 d 4MATIC 쿠페", "메르세데스-AMG" → "AMG" (원문은 variantNote `sourceName`에 보존) |

## 4. 운영 방법 (요약 — 상세 `VEHICLE_MASTER_PIPELINE.md`)
1. 가격표가 바뀐 브랜드의 `raw2/<모델>.json` 만 다시 추출 → `node tools/vm-build-all.js`
2. trimId 가 바뀌어 배포가 멈추면: 의도한 변경이면 registry `aliases` 에 {옛 id: 새 id} 추가 후 재실행, 새 트림만 추가된 경우는 그대로 통과
3. 이미지: 새 라인업은 Commons 검색 도구(사용자 PC) → 결과 첨부 → 후보 선정 → 재빌드
