## 2. 수입차 공통 사실 (구조 판단)
- 수입 브랜드 가격표는 대부분 **모델명 + 권장소비자가 2열**뿐(BMW·포르쉐·미니·랜드로버). 옵션/패키지 가격·색상 추가금·기본품목·연식은 공식 문서에 없음 → 규칙대로 null/빈 배열, `issues` 기록. 폴스타(보도자료 팩 가격), 벤츠 일부(보도자료 옵션명)만 예외.
- Trim = 가격표 행(예 `530i xDrive M 스포츠`, `E 300 4MATIC 익스클루시브`, `디펜더 110 D300 X-Dynamic HSE`), Lineup = 파워트레인 그룹(가솔린/디젤/PHEV/EV, M/AMG 별도). 벤츠·볼보처럼 하이브리드/전동화가 별도 페이지인 브랜드는 별도 모델.
- modelYear: 가격표에 연식이 없는 브랜드(BMW 등)는 기준일 연도 2026 + "MY 미표기" 이슈.
- 세대코드 전부 null(공식 미표기). 차체 enum 보정: 투어링→WAGON, 컨버터블/로드스터/SL→CONVERTIBLE, 액티브 투어러→MPV.
