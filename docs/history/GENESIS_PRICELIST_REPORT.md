# 제네시스 가격표 반영 보고 (v172)

기준: 제네시스 공식 가격표 PDF 「2026년 9월 1일, 개별 소비세 5% 기준」 — 사용자가 genesis.com 다운로드센터에서 저장한 파일 16개(17 모델; GV60 마그마는 GV60 가격표 9~11쪽에 포함).
중복 파일: G80=G80 블랙, G90 4종 동일, GV80=GV80 블랙, GV80 쿠페=쿠페 블랙 → 실제 문서 10종.

## 차량가격으로 판단해 넣지 않은 항목 (원칙: Vehicle Master 에 판매가 저장 금지)
판매가격·공급가액·추천 차량 합계, 그리고 이미 별도 라인업/트림인 단계 가격 — 예: G80 3.5 터보 +6,600,000, 스포츠 패키지 +4,000,000, GV80 3.5 터보 +5,500,000, GV60 퍼포먼스 AWD +8,400,000. 각 raw 파일 `issues[]` 에 기록.

## 남은 확인 사항
- GV70 **그래파이트 패키지**, G70 **벌리 블루 매트**: 가격표에는 있거나/없지만 현 트림 구성과 맞지 않아 트림 추가 없이 이슈로만 기록(trimId 고정 원칙).
- G90 뒷좌석 컴포트 패키지Ⅱ: 앞좌석 컴포트와 동시 선택 시 2,400,000 (단독 2,900,000) — 단독가로 기록, 조건은 이슈.
- GV80 파퓰러 패키지: 2WD 5,550,000 / AWD 6,200,000 → 기존 행 2WD 가격 + "[AWD 전용]" 행 추가.
- 제네시스 액세서리(보호 필름·엔터테인먼트 등)는 옵션이 아닌 raw `accessories[]` 로만 보관.

## 파이프라인 수정 (전 브랜드 영향)
- `vm-build-brand.js`: 가격표 연비 행(`specsPriceList[].lineup`)이 항상 첫 라인업에 붙던 버그 수정 → 기아 71·KGM 3·르노 5 레코드가 올바른 라인업으로 이동(개수 변화 없음).
- 같은 트림명이 여러 라인업에 있을 때(예: 2.5/3.5 "스포츠 패키지") 제원 열 제목과 맞는 라인업에만 연결.
- raw `pricelistSource` → 소스 `src-<brand>-pricelistpdf-<model>` 로 모델·라인업·연비 레코드에 연결.
